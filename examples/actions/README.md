# Community action examples

Import `starter-recipes.json` with **Import shared action recipes**. Review and preview each recipe before running it. Copy recipes preserve the source by ending with `restore`; meeting-note creates an inbox note in the terminal UI.

To contribute, add a version 1 `jotline-actions` JSON file and describe its effect, required template/target setup, and whether it changes the source. Include a concrete input/output example. Do not include personal note IDs, private text, credentials, shell commands, or network integrations. Use unique descriptive names; imports never replace existing actions.
