# Native terminal reports

Automated Pilot and PTY checks do not close
[issue 2](https://github.com/CaulShiver/jotline/issues/2) or
[issue 3](https://github.com/CaulShiver/jotline/issues/3). Those need a
human-recorded report for one native macOS or Windows terminal, and a
screen-reader pass, using [the terminal checklist](../terminal-testing.md).

Add a short Markdown file here named for the OS and terminal, for example
`macos-terminal-16.md`. Include no personal notes. Close the matching issue
only after that file is merged and any failures it names are fixed.
